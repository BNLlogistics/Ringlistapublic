Delad ringlista

Koppla den delade listan

Görs en gång. Koden låter appen läsa och spara i gängets gemensamma lista på GitHub, och sparas bara i den här telefonen.

  1. Öppna GitHub och skapa en ny kod.
  2. Namn: Delad ringlista. Giltighet: No expiration (eller ett år).
  3. Resource owner: välj organisationen (inte ditt eget namn).
  4. Repository access: Only select repositories → välj Ringlista.
  5. Permissions → Repository → Contents: Read and write.
  6. Tryck Generate token, kopiera koden och klistra in här.
